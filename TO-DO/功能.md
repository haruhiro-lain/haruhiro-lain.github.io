# 草稿区在线编辑 → Git 同步

## 需求描述

在博客首页上直接编辑"草稿区"的内容——即根目录下 `TO-DO/` 文件夹中的 Markdown 文档，支持**增、删、改**操作，提交后自动推送至远端分支。

### 操作范围

- 目录：`TO-DO/*.md`
- 操作：新增文件、编辑文件内容、删除文件

---

## 实现方案：Astro API + GitHub REST API

> 不引入第三方 CMS，利用 GitHub Contents API 直接读写仓库文件，保持轻量。

### 架构

```
浏览器 (/drafts 页面)
  │
  ├─ GET  /api/drafts       → 列出 TO-DO/ 下所有 .md 文件
  ├─ GET  /api/drafts/[slug] → 读取单个文件内容
  ├─ POST /api/drafts       → 新建文件
  ├─ PUT  /api/drafts/[slug] → 更新文件
  └─ DELETE /api/drafts/[slug] → 删除文件
         │
         ▼
  Astro API Routes (SSR 模式)
         │
         ▼
  GitHub REST API (Contents endpoint)
         │
         ▼
  GitHub 仓库 → commit + push 到目标分支
```

### 关键依赖

- GitHub Contents API：读写文件、自动生成 commit
- 无需额外 npm 包，只需 `fetch`

### 实现步骤

#### 1. 启用 Astro SSR

```diff
// astro.config.mjs
export default defineConfig({
+ output: 'server',   // 或 'hybrid'
  // ...
});
```

#### 2. 创建 API 路由

在 `src/pages/api/drafts/` 下创建 API 端点，调用 GitHub Contents API：

```
src/pages/api/drafts/
├── index.ts          # GET 列表 / POST 新建
└── [slug].ts         # GET 详情 / PUT 更新 / DELETE 删除
```

核心逻辑：

```ts
// 通用：调用 GitHub Contents API
const GITHUB_API = 'https://api.github.com/repos/<owner>/<repo>/contents/TO-DO';
const BRANCH = 'main'; // 或 'draft'

// 读取文件
// GET /repos/{owner}/{repo}/contents/{path}

// 创建/更新文件（需提供 sha 才能更新）
// PUT /repos/{owner}/{repo}/contents/{path}
// body: { message, content: base64, branch, sha? }

// 删除文件
// DELETE /repos/{owner}/{repo}/contents/{path}
// body: { message, sha, branch }
```

#### 3. 认证

在 `.env` 中配置 GitHub Personal Access Token：

```bash
GITHUB_TOKEN=ghp_xxxxxxxxxxxx
```

API 路由中通过 `Authorization: Bearer <token>` 请求头传递。

#### 4. 前端编辑页面

创建 `src/pages/drafts.astro`，内嵌一个 Vue 组件：

- 左侧：文件列表（点击选择）
- 右侧：Markdown 编辑器（`<textarea>` 或轻量 Monaco/CodeMirror）
- 底部：保存 / 删除 / 新建 按钮

#### 5. 推送远端

GitHub Contents API 的 PUT/DELETE 请求天然支持：
- 每次请求自动生成一个 commit
- commit 落在指定 branch 上
- 相当于自动 push

### 文件对照

| 文件 | 作用 |
|------|------|
| `.env` | 存 `GITHUB_TOKEN`（勿提交） |
| `astro.config.mjs` | `output: 'server'` |
| `src/pages/drafts.astro` | 编辑器页面 |
| `src/pages/api/drafts/index.ts` | 列表 + 新建 |
| `src/pages/api/drafts/[slug].ts` | 读取 + 更新 + 删除 |
| `src/components/DraftEditor.vue` | 编辑器组件（列表 + Markdown 编辑区） |
